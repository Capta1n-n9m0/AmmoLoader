# FAQ

## Is this the official Ammo Loader+ mod?

No. This is an **unofficial fork** maintained by [ukaszstm](https://github.com/ukaszstm) because the [original mod](https://mods.factorio.com/mod/ammo-loader) by SilentCrim has not been updated for Factorio 2.1.

## Can I use this together with the original ammo-loader mod?

**No.** The mods conflict. Disable `ammo-loader` before enabling `ammoloader21`.

## Will my save work after switching from ammo-loader?

Entity names are unchanged, so saves should work after removing the original mod and enabling this fork. Always back up your save first.

## Does this add new features?

No. Version 2.1.0 contains only the changes required for Factorio 2.1 compatibility.

## Where do I report bugs?

Open an issue on [GitHub](https://github.com/ukaszstm/AmmoLoader/issues).

For bugs that also exist in the original 2.0 version, consider reporting to the [original mod discussion](https://mods.factorio.com/mod/ammo-loader/discussion) as well.

## Does this work with Space Age / quality?

The mod targets Factorio 2.1 base game. It has been tested to load on 2.1.9. Compatibility with all overhaul modpacks is not guaranteed.
